# Отчёт о проверке конфигурации nginx

**Дата:** 18.10.2026  **Результат:** успешно  **Окружение:** тестовый стенд (nginx 1.24, самоподписанный сертификат, не боевой сервер)

## Что проверено
`nginx -t` на `deploy/nginx-ryazdetailing-https.conf` + `nginx-security-headers.conf`, затем реальный запуск nginx вместе с бэкендом (`NODE_ENV=production`, `SITE_DIR`, `SITE_URL`) и скрипт `deploy/check-production.sh`: **44 PASS, 0 FAIL** (3 SKIP: цепочка самоподписанного сертификата, IPv6 без AAAA-записи, `certbot` — это проверяется только на сервере).
- редиректы HTTP → HTTPS и www → без www (301);
- HSTS (год), CSP, `nosniff`, `X-Frame-Options`, `Referrer-Policy`, `Permissions-Policy` на страницах и на API; версия nginx не раскрывается;
- cookie сессии за HTTPS-прокси: `HttpOnly`, `Secure`, `SameSite=Strict`, токена нет в теле ответа;
- gzip для CSS/JS; кеш: HTML `no-cache`, картинки месяц одним заголовком;
- закрыты `/.env`, `/.git/`, `/data/*.db`, `/node_modules/`, `/backups/`, а также `package.json`, `server.js`, `deploy/` (не отдаются);
- `robots.txt`, `sitemap.xml`, `favicon.ico`, 404 на несуществующей странице, проксирование `/api` и `/health`.

## Дополнительно проверено (19.10.2026)
- Сертификат: срок ≥ 14 дней и покрытие `ryazdetailing.ru` + `www`; проверка **ловит** короткий срок (тест на сертификате в 2 дня → FAIL) и недоверенную цепочку (самоподписанный → FAIL).
- TLS 1.2 и 1.3 работают, TLS 1.0 и 1.1 отклоняются (alert protocol version) для обоих имён; HTTP/2 включён; смешанного содержимого на страницах из sitemap нет.
- Ложная тревога по TLS: на одном из прогонов проверка ошибочно показала «TLS 1.1 принят» — она разбирала вывод `openssl s_client`, где указан *пробуемый* протокол. Опыт на исходном конфиге показал, что TLS 1.0/1.1 отклонялись и до правки; проверка исправлена (успехом считается только реально согласованный шифр). Параметры TLS всё равно заданы в каждом 443-блоке — на случай других версий nginx.

## Найдено и исправлено
- Для картинок отправлялись два заголовка `Cache-Control` (`expires` + `add_header`) — теперь один.

## Чего это НЕ доказывает (делается на боевом сервере)
- Реальный сертификат Let's Encrypt и автопродление certbot.
- Строки `listen [::]` (IPv6): в тестовой среде IPv6 нет, при проверке они были временно убраны.
- Brotli (в тестовой сборке nginx его нет), HTTP/3, лимиты запросов под нагрузкой.

**После деплоя запустите:** `bash deploy/check-production.sh ryazdetailing.ru` (с `ADMIN_LOGIN`/`ADMIN_PASSWORD` в окружении — проверит ещё и cookie входа) и пришлите вывод.
